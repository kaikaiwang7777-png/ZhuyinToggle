# 焦點往返實驗宿主（限可丟棄資料）

此程式是獨立、非正式的互動實驗，不是 ZhuyinToggle 正式功能。只允許操作自身視窗的 A／B 文字方塊及按鈕，不控制其他程序，也不注入鍵盤。按 Win+Alt+C 時，僅在實驗已由使用者啟動、同一視窗前景、A 有焦點、每次均勾選完成組字及沒有未判讀結果時，才嘗試寫入並回讀 REG_SZ。每組開始前會將原始設定備份在本機使用者的 LocalAppData；不記錄文字內容。

## 操作

1. 關閉會占用 Win+Alt+C 的正式工具，只使用微軟注音及空白或可丟棄的測試內容。選擇 A、B 或 C，按「開始一組實驗」，先以人工注音輸入確認繁體基準。
2. 完成組字、提交候選字並確認不再輸入後，勾選同意，再點回 A；按 Win+Alt+C。A 組不移焦點；B 組 A→按鈕→A；C 組 A→B→A，不在 B 組字。
3. 實際在 A 以注音輸入「電腦／电脑」，提交後點選觀察結果。程式不自動判讀文字。記下閃爍、組字中斷、輸入遺失等不能由程式可靠判斷的狀況。每次重新勾選確認；每組至少做十次單向切換，並確認是五次繁簡往返。
4. 按「結束並安全還原原值」，確認回讀，且用正常注音實際確認輸出。每一組分別建立與還原備份，不混合條件。若提示外部變更或還原失敗，停止、不覆蓋；可以選擇不還原退出，並自行檢查原值及 Windows 原生設定。

## 重要限制

- WM_IME_* 與候選字事件僅提供本宿主能觀察到的證據，沒有收到事件不證明所有 TSF 組字已結束。實驗仰賴使用者明確確認已完成組字，不應在日常工作或有價值的文字上使用。
- 程式檢查前景、A／目標控制項、最後輸入時間、文字與選取位置；發生非預期狀況不強制搶回焦點。檢查與動作不是原子操作，無法排除所有競態。執行期間請勿操作其他程式或同時按鍵。
- 登錄檔比較後寫入不是跨程序原子交易；兩次檢查之間的外部改寫，或修改後又改回原值，無法保證偵測。測試期間請勿同時修改該設定。異常終止後請依本機備份與原生設定人工核對。
- 日誌中的焦點事件、選取範圍與文字相同只是觀察，不是無閃爍、無中斷或成功切換的證明；實際輸出及副作用由人判讀。單機成功也不代表記事本、Chrome 或其他 Windows 版本適用。
- 不使用剪貼簿、完成字注入、Alt+Tab、AttachThreadInput、跨程序焦點操控或重啟輸入法。關閉視窗解除快捷鍵。

建置：`dotnet build tools/FocusResetProbe/FocusResetProbe.csproj -c Release`。目前沒有把此功能整合至正式產品。
