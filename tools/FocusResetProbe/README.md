# 簡化注音焦點對照工具（實驗用）

此工具不屬於正式產品，只供明確啟動的獨立、可丟棄輸入測試使用。按「開始測試」後，依畫面提示用微軟注音反覆輸入「電腦中國」並提交組字；程式自動檢查固定測試詞與進度，不需要選擇模式或判讀結果。按「結束並還原」可停止。請先關閉正式工具、不要在同一時間操作其他應用或修改輸入法設定。

工具依序使用 A 不改焦點、B 經本視窗按鈕、C 經本視窗另一文字框。每組先檢查繁體基準，再計畫進行五次往返；若前一次輸出不是有效起始模式，該反向切換記為 NOT TESTED，不把目標字形相符當成完整切換。若失去焦點、輸入法身分不符、組字狀態不明、登錄值與預期不同或原始文字及選取無法恢復，停止而不搶回焦點。失敗及未知結果不是產品功能的測試通過。

啟動後以本執行緒 `ITfInputProcessorProfileMgr::GetActiveProfile` 核對微軟注音的語言、CLSID 與 Profile GUID；觀察測試欄位組字開始／結果／結束事件及 IMM 狀態。對可供判讀的詞語只接受固定測試字串，拒絕貼上；程式只清空自有可丟棄測試欄，不注入中文字。這些觀察不是對 Windows 所有 TSF 私有狀態的完整證明。焦點往返經 `BeginInvoke` 讓訊息循環有機會處理事件，並確認實際事件順序。焦點返回會觸發 WinForms 全選，僅在確認仍為測試視窗且使用者沒有新輸入時於自有欄位還原選取範圍；這是已觀察到的副作用，非無感操作。

原始 REG_SZ 先備份至本機使用者資料夾；結束前比較最近觀察的值，沒有外部變更時才還原並回讀。比較與寫入不是跨程序原子交易，不能保證偵測在取樣之間發生、又恢復原狀的更改。異常終止時備份仍留在本機，需要人工核對。程式不記錄非測試詞的文字；測試紀錄不提交個資。不得用此工具操作別的應用程式的焦點，也不把單機測試當成 Chrome 或記事本已驗證。

建置：`dotnet build tools/FocusResetProbe/FocusResetProbe.csproj -c Release`。本輪先導實測結果與未完成項目見 `docs/ime-validation.md`。

目前測試順序為 B 五次、C 五次、A 一次；每個樣本有唯一序號與輸入修訂號。逾時為 NOT TESTED；不允許舊事件判讀新樣本。本機一次受控鍵位測試 B、C 均 5/5，詳細證據與限制見 `docs/ime-validation.md`；不可推論第三方程式安全。
