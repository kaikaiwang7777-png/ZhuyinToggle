# 焦點重置安全性探針（唯讀，未實作切換）

這是獨立觀察原型，不是產品功能，也不是自動焦點重置的實作。它註冊 Win+Alt+C，在原型的測試輸入欄位有焦點且原型為前景時，讀取該登錄值、焦點及選取位置；不記錄輸入的文字內容。程式無法可靠判斷新版微軟注音 TSF 組字／候選字狀態，因此**無條件中止，不寫登錄檔、不改焦點**。不操作記事本、Chrome 或其他程序。關閉程式釋放快捷鍵；請勿與正式工具同時執行。

這不是使用者要求之焦點重置測試的完成版。要進入有狀態修改的測試，需先找到可證明測試欄位組字／候選字均已結束且使用者沒有繼續輸入的安全方法，並定義在焦點移走時停止還原的可驗證流程。不能把 IMM 的一般狀態、HKL 或人工等待單獨視為完整證明。

建置：`dotnet build tools/FocusResetProbe/FocusResetProbe.csproj -c Release`。UI 觀察、焦點重置與實際輸出驗收尚未進行。
