# ZhuyinToggle 人工驗收開發版

此版本尚未通過實機驗收，不保證微軟注音實際輸出會立即改變。圖示只反映讀回的登錄設定，並非實際輸出的確認。

1. 先從系統匣正常結束舊版，避免同時操作同一設定。
2. 將整個 ZIP 解壓到固定資料夾，雙擊 `ZhuyinToggle.exe`。程式會出現在通知區域（可能位於隱藏圖示中）。
3. 在空白記事本使用微軟注音輸入「電腦中國」。
4. 按 **Win + Alt + C**，再輸入同樣詞語，觀察是否改為「电脑中国」；再按一次切回。
5. 如有問題，雙擊系統匣圖示開啟設定，按「查看最近一次命令」並複製結果。

左鍵單擊圖示可切換；右鍵提供固定設定繁體、簡體及結束。設定可修改快捷鍵，並可由您自行啟用登入自動啟動（預設關閉）。若快捷鍵被占用，仍可使用滑鼠。請勿將日常重要內容用作測試。

本程式以 Windows PowerShell `-NoProfile -NonInteractive -EncodedCommand` 執行原始 reg 命令，不要求系統管理員權限；命令成功不代表實際輸出已更新。設定保存在 `%LOCALAPPDATA%\ZhuyinToggle-Manual`，不讀取舊版設定。

### 實驗性自動視窗往返

預設啟用「熱鍵切換後，自動重新啟用原視窗」，候選間隔為 50 毫秒；設定視窗可關閉或改為 100、150 毫秒。請先結束上一段注音組字，再按熱鍵並留在原視窗繼續輸入。請觀察是否成功切換、是否閃窗，以及游標、選取和原文字是否完整。此功能會真正短暫啟用工作列再嘗試返回，不保證無干擾；未完成組字時的行為尚未驗證。若操作期間您切換視窗或繼續輸入，程式會嘗試取消後續返回。系統可能拒絕前景切換；此時設定可能已更新，但不會再次切換或自動還原。查看「最近一次命令」可取得結果與失敗原因。系統匣圖示仍僅表示設定值，不表示實際輸出已確認。
