# 微軟注音切換可行性：實驗階段

**尚未完成實際輸出驗證，不可作為正式發布的依據。**

## 已觀察結果

- 在測試環境中，`HKCU\SOFTWARE\Microsoft\IME\15.0\IMETC` 的 `Enable Simplified Chinese Output` 為 **REG_SZ**，原值是字串 `0x00000000`；不能假設它是 DWORD。
- 已暫時將字串改成 `0x00000001` 並重新讀取，隨後還原為 `0x00000000`、REG_SZ。這只證明讀寫及還原，**不證明實際輸出已切換**。
- 未成功完成記事本或瀏覽器實際輸入觀察；因此即時生效、重新載入方式以及不同 Windows 版本相容性均未知。
- Windows SDK 說明的其他 IME 政策不等於此值的即時重新載入介面；在取得可靠證據前，不應推測廣播訊息、重啟程序或更改其他設定能解決問題。

## 互動式驗證

本工具只用於測試，不提供給一般使用者當成切換程式。請先關閉正在輸入的工作，準備一個空白記事本及瀏覽器文字框，選擇微軟注音。先輸入會有不同繁簡字形的同一詞語，記錄原設定的實際輸出。

在一般使用者 PowerShell 中執行：

```powershell
./tools/Test-ImeSetting.ps1        # 僅讀取
./tools/Test-ImeSetting.ps1 -Run   # 備份、暫改、互動觀察、還原
```

保留 PowerShell 視窗，在兩個應用程式中用微軟注音再次輸入同一詞語並記錄輸出；按 Enter 才還原設定，再次確認輸出。分別測試原值 0 和 1 的往返、現有與新開視窗。若中斷或程式遭強制終止，`finally` 可能不會執行；請使用螢幕顯示的 JSON 備份核對並手動還原，並確認資料類型。實驗期間若 Windows 設定被其他程序更改，腳本不會覆蓋該變更。切勿將個人備份檔提交至公開倉庫。
